# CycPep Studio 前端演示脚本（25 秒）

## 录屏与配音

| 时间 | 画面 | 配音 |
| --- | --- | --- |
| 00:00–00:05 | 打开前端，全屏点火界面出现。镜头停留在标题和靶点输入区。 | “这是 CycPep Studio，一个面向环肽设计的智能工作台。” |
| 00:05–00:13 | 输入一个可唯一解析的靶点，快速展示正式项目审查和 GPU 审批选项。 | “输入目标靶点，系统即可建立新的设计项目，并配置首轮计算策略。” |
| 00:13–00:18 | 点击 `Create and launch`。 | “点击点火，项目进入统一工作流。” |
| 00:18–00:25 | 转入该 Launcher 运行绑定的监控界面，展示项目、任务和结果区域；若已到审批点，让提醒卡进入画面。 | “随后可以在工作台中持续查看任务、候选结构、计算证据和需要人工确认的资源审批。” |

## 录屏提示

- 全程控制在 25 秒左右，不展开技术细节。
- 鼠标移动放慢，点击前停顿约半秒。
- 点火前让靶点和 `Create and launch` 同时出现在画面中。
- 进入监控界面后停留 5–7 秒，让观众看清完整布局。
- 不展示终端、日志、代码或配置文件。
