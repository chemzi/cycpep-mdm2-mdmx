# CycPep Studio 项目演示视频脚本（4 分 35 秒）

## 演示目标

用一条真实闭环讲清价值：输入靶点、建立环肽项目、展示 GPU 预算与审批，再进入 Prediction、Critic 和下一轮计划。画面以前端工作台为主，不把暂定估算、探索 shortlist 或不可用结果包装成已校准、已通过结果。

## 拍摄准备

- 准备可快速返回的 MDM2/MDMX 环境和一个正式 `awaiting_approval` 运行。
- 另准备一个有明确运行 ID、已正式推进到 Prediction/Critic/Planner 的运行，用于耗时计算后的标识化跳切。
- “自动批准第一个 GPU 关口”设置明确 GPU 分钟、槽位和候选上限；后续计划仍人工批准。

## 录屏取舍

- 不展示 SSH、本地路径、原始日志或配置文件。
- 如果自动批准不满足上限，停在等待批准并演示人工批准。
- 耗时计算后只跳切到明确标出运行 ID 的正式运行，不使用伪造成功画面。
